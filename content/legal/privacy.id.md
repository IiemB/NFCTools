# Kebijakan Privasi

## Ringkasnya

NFC Tools tidak mengumpulkan, menjual, atau membagikan data Anda. Tidak ada akun, iklan, atau analitik, dan aplikasi tidak mengirim apa pun kepada pengembang kecuali Anda memilih untuk mengirim laporan.

## Yang Tetap di iPhone Anda

Tag yang Anda simpan (ID, jenis, isi, nama panggilan, ikon, dan warnanya), pengaturan Anda, pilihan widget dan Pusat Kontrol, serta log aktivitas aplikasi hanya disimpan di iPhone ini. Menghapus tag akan menghapusnya.

## Tag NFC

Saat Anda memindai tag, iPhone Anda membaca datanya, dan data itu hanya disimpan jika Anda memilih untuk menyimpannya. Data tag tidak pernah diunggah.

## Saat Data Meninggalkan iPhone Anda

Hanya saat Anda memilihnya: misalnya, saat Anda mengekspor tag ke file dan membagikannya, atau menyalin suatu nilai. Tautan di aplikasi, seperti halaman pengembang, dibuka di browser Anda, yang memiliki kebijakan privasinya sendiri.

Untuk menampilkan versi terbaru ketentuan ini, aplikasi mengunduhnya dari GitHub. Permintaan itu tidak menyertakan data Anda, meskipun GitHub dapat melihat alamat IP Anda, seperti situs web lainnya.

## Laporan ke Pengembang

Halaman Diagnostik memiliki tombol Kirim Laporan. Laporan hanya dikirim ketika Anda mengetuknya, dan Anda dapat melihat isinya sebelum mengirim. Laporan berisi hasil Diagnostik, detail dasar seperti model iPhone dan versi iOS, catatan yang Anda tambahkan, serta log aktivitas aplikasi, yang membantu melacak masalah dan mungkin memuat beberapa detail tentang tag yang pernah Anda gunakan.

Log dienkripsi di iPhone Anda sebelum dikirim, sehingga hanya pengembang yang dapat membacanya; layanan yang mengantarkan laporan tidak dapat membacanya. Laporan hanya digunakan untuk memperbaiki masalah. Tidak ada yang pernah dikirim secara otomatis.
